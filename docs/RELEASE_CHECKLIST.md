# Version 1.0 release checklist

## Product

- [ ] Every item in `docs/SPEC.md` release acceptance passes.
- [ ] Quick, Full and Release modes behave as documented.
- [ ] Known limitations and residual-risk semantics are explicit.

## Verification

- [ ] Unit, parser-fixture, integration and end-to-end tests pass.
- [ ] Clean macOS and Linux installation walkthroughs pass.
- [ ] CLI, MCP and GitHub Action policy parity is verified.
- [ ] Code Clearance successfully evaluates its own repository.

## Trust and legal

- [ ] Public licence is approved and present.
- [ ] Every reused/adapted component has an exact source, commit and licence record.
- [ ] Third-party notices and required copyright text are published.
- [ ] Security policy and private reporting path work.
- [ ] Release binaries have checksums and provenance/signing where supported.

## Launch readiness

- [ ] README five-minute quick start works from a clean machine.
- [ ] Demo shows confirmation, false-positive rejection, verified fix and residual risk.
- [ ] Examples cover JavaScript/TypeScript, Python and Go.
- [ ] Changelog and release notes are complete.
- [ ] Contributor starter issues are prepared.
- [ ] Marketing claims match tested behavior.
