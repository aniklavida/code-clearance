# Security policy

## Current status

**Planned for v1.0:** no supported release or private security-reporting path is published yet.

## Reporting

Do not publish suspected vulnerabilities in a public issue.

**Planned for v1.0:** a private reporting address or GitHub private vulnerability-reporting workflow will be added before the first public release. Until that path is live, this document does not provide a working private channel; do not treat it as one.

When private intake is available, reports should include the affected version or commit, reproduction steps, impact and safe supporting evidence. Do not include real secrets or data belonging to others.
