# Contributing

Code Clearance is not accepting implementation contributions until the foundation and public licence decisions are complete.

When contribution opens:

1. Read `AGENTS.md` and the relevant public design documents.
2. Open or reference an issue before large changes.
3. Keep changes scoped and include tests/fixtures for behavior.
4. Explain what evidence verifies the change and any remaining limitations.
5. Do not introduce copied/adapted code without provenance and licence review.

Security vulnerabilities must follow `SECURITY.md`, not a public issue.
