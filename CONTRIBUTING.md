# Contributing

**Status: Planned for v1.0.** Code Clearance is not accepting implementation contributions until the foundation and public licence decisions are complete.

When contribution opens:

1. Read `AGENTS.md` and the relevant public design documents.
2. Open or reference an issue before large changes.
3. Keep changes scoped and include tests and fixtures for behavior.
4. Explain what evidence verifies the change and any remaining limitations.
5. Do not introduce copied or adapted code without provenance and licence review.

For scanner adapter work, start with [docs/ADAPTER_GUIDE.md](docs/ADAPTER_GUIDE.md). Public behavior must use the repository's status vocabulary: **Implemented and tested**, **Experimental**, **Planned for v1.0** or **Unsupported**.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not a public issue. The private reporting path is **Planned for v1.0** and is not currently available.
